# Where each check's flags point

What "Show on document" does for every registered check, so the audience is never left looking at an unmarked page. The viewer sorts every flag into four kinds from the flag's own data (a box on a page, a whole page, a whole file, the case as a whole; see [frontend.md](frontend.md) section 6.1), so the answer below is a description of what to expect, not a list of exceptions: whatever a check does at run time, the viewer handles all four kinds the same way.

Generated by `uv run python backend/scripts/audit_flag_locations.py --observed <json> --out docs/flag-locations.md`: a static pass over every `make_flag` call (the code sites), plus the flags built by the red-team attacks, the sample scenarios, the showcase documents and the whole test suite. "Seen" counts are flags observed in those runs. A box is drawn only when the figure has a position on the page; on a scanned page whose figure could not be located, or for a check about the file itself, the flag has no region and the file is framed instead.
